  This unit introduces the key concepts of a programming environment and the tools and resources used to write, test, debug, and run code effectively.

  code: |-
    <p>When you start programming, you’re not just writing code in isolation—you’re

    working within a complete setup of tools that help you build, test, and manage

    software. This setup is called a programming environment. Understanding how it

    works will help you become more efficient, organised, and confident when

    developing applications.</p>

    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;"> </div>

    <h5

    style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">

    TEXT EDITOR OR IDE</h5>

    <p>Every programming task starts with writing code. This is done using tools

    designed to make coding easier and more structured.</p>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Text Editor</strong>

    <p style="margin: 6px 0 0;">A lightweight tool used to write and edit code,

    offering basic features like syntax highlighting and formatting.</p>

    </div>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Integrated Development Environment (IDE)</strong>

    <p style="margin: 6px 0 0;">A more advanced tool that includes features like

    debugging, code completion, and project management.</p>

    </div>

    <div

    style="border-left: 4px solid #00C9B1; background: #f9fafb; padding: 12px 16px; margin: 16px 0;">

    <h5 style="margin-top: 0;">Key Info</h5>

    <p style="margin-bottom: 0;">Both tools allow you to write code, but IDEs

    provide additional built-in functionality to streamline development.

    <em>Read more <a

    href="https://www.geeksforgeeks.org/blogs/ide-vs-text-editor/"

    target="_blank" rel="noopener">here</a>.</em></p>

    </div>

    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;"> </div>

    <h5

    style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">

    INTERPRETER OR COMPILER</h5>

    <p>Once code is written, it needs to be translated into a form that a computer

    can understand and execute.</p>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Compiler</strong>

    <p style="margin: 6px 0 0;">Translates the entire program into machine code

    before execution. Common in languages like C and C++.</p>

    </div>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Interpreter</strong>

    <p style="margin: 6px 0 0;">Executes code line by line, commonly used in

    languages like Python and JavaScript.</p>

    </div>

    <p><em>Read more <a

    href="https://www.geeksforgeeks.org/compiler-design/difference-between-compiler-and-interpreter/"

    target="_blank" rel="noopener">here</a>.</em></p>

    <blockquote><em>The way your code is executed affects performance, debugging,

    and development speed.</em></blockquote>

    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;"> </div>

    <h5

    style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">

    DEBUGGING TOOLS</h5>

    <p>Even experienced programmers make mistakes. Debugging tools help identify and

    fix these issues efficiently.</p>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Breakpoints</strong>

    <p style="margin: 6px 0 0;">A breakpoint is point in the code where program

    execution temporarily pauses, or stops during debugging.</p>

    </div>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Watchlists</strong>

    <p style="margin: 6px 0 0;">A watchlist is a tool in debugging software that

    helps programmers keep an eye on certain variables, expressions, or memory

    spots as their program runs.</p>

    </div>

    <div

    style="border-left: 4px solid #FF0200; background: #f9fafb; padding: 12px 16px; margin: 16px 0;">

    <h5 style="margin-top: 0;">Common Mistakes</h5>

    <p style="margin-bottom: 0;">Ignoring debugging tools can make problem-solving

    slower and more frustrating.</p>

    </div>

    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;"> </div>

    <h5

    style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">

    VERSION CONTROL SYSTEMS</h5>

    <p>Managing changes in code is essential, especially when working on larger

    projects or in teams.</p>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Version Control (e.g. Git)</strong>

    <p style="margin: 6px 0 0;">Tracks changes to code, supports collaboration,

    and helps manage different versions of a project.</p>

    </div>

    <div

    style="border-left: 4px solid #C755FF; background: #f9fafb; padding: 12px 16px; margin: 16px 0;">

    <h5 style="margin-top: 0;">Why This Matters</h5>

    <p style="margin-bottom: 0;">Version control allows multiple developers to

    work on the same project without overwriting each other’s work.</p>

    </div>

    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;"> </div>

    <h5

    style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">

    BUILD TOOLS AND AUTOMATION</h5>

    <p>Programming often involves repetitive tasks. Build tools and automation

    scripts help streamline these processes.</p>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Build Tools</strong>

    <p style="margin: 6px 0 0;">Software utility or tool that automates the

    process of compiling source code files into executable binaries or results.

    </p>

    </div>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Automation Scripts</strong>

    <p style="margin: 6px 0 0;">Handle repetitive tasks like testing, deployment,

    and packaging applications.</p>

    </div>

    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;"> </div>

    <h5

    style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">

    LIBRARIES AND FRAMEWORKS</h5>

    <p>Developers don’t always need to build everything from scratch. Libraries and

    frameworks provide reusable components.</p>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Libraries</strong>

    <p style="margin: 6px 0 0;">Collections of pre-written code that can be reused

    for common tasks.</p>

    </div>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Frameworks</strong>

    <p style="margin: 6px 0 0;">Structured platforms that provide a foundation for

    building applications efficiently.</p>

    </div>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Interface Design</strong>

    <p style="margin: 6px 0 0;">The process of creating user-friendly and visually

    appealing software interfaces.</p>

    </div>

    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;"> </div>

    <h5

    style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">

    DOCUMENTATION AND RESOURCES</h5>

    <p>Learning and problem-solving are continuous in programming. Documentation

    provides the guidance needed to use tools effectively.</p>

    <div

    style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

    <strong>Documentation &amp; Tutorials</strong>

    <p style="margin: 6px 0 0;">Help programmers understand tools, languages, and

    frameworks through guides and examples.</p>

    </div>

    <div

    style="border-left: 4px solid #FF7900; background: #f9fafb; padding: 12px 16px; margin: 16px 0;">

    <h5 style="margin-top: 0;">Examples</h5>

    <p style="margin-bottom: 0;">Online documentation, tutorials, and community

    forums are commonly used to solve problems and learn new skills.</p>

    </div>

    <div style="border-top: 1px solid #e5e7eb; margin: 16px 0;"> </div>

    <h5

    style="text-transform: uppercase; font-size: 0.8rem; letter-spacing: 0.05em; color: #6b7280; margin-bottom: 8px;">

    KEY TAKEAWAYS</h5>

    <p>A programming environment brings together all the tools needed to build

    software—from writing and debugging code to managing versions and automating

    tasks. Understanding how these components work together helps you develop more

    efficiently, collaborate effectively, and produce high-quality applications.

    </p>
