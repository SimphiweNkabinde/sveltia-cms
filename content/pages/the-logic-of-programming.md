      instructions to follow. However, these instructions are not random—they follow
      a logical structure that ensures the program behaves correctly and produces
      the desired outcome.</p>
    <p>Understanding the logic of programming helps you think like a developer,
      allowing you to design clear, efficient, and reliable solutions to problems.
    </p>

    <p>Programming logic can be understood as a set of fundamental building blocks
      that determine how a program operates. These elements work together to control
      the flow of a program and how it processes information.</p>

      <strong>Sequence</strong>
      <p style="margin: 6px 0 0;">Programs execute instructions in a specific order,
        one step after another. The sequence determines how tasks are carried out
        from start to finish.</p>
    </div>

      <strong>Conditions</strong>
      <p style="margin: 6px 0 0;">Programs make decisions based on conditions. For

        action is performed.</p>

      <p style="margin: 6px 0 0;">Loops allow programs to repeat actions until a

      </p>

      style="background: #fdfdfe; border: 1px solid #e5e7eb; border-radius: 10px; padding: 14px 16px; margin-bottom: 12px; box-shadow: 0 1px 2px rgba(0,0,0,0.04);">

      <p style="margin: 6px 0 0;">Functions are reusable blocks of code that perform
